Introduction

I wrote this tutorial for learning a new programming language. It is not intended to teach specific syntax or best practices. It just gives you a general line in the direction of learning. You should investigate yourself how to implement a project in the chosen language and framework. At first, choose a practical project. Then proceed from a simple terminal application to a web application with GUI and user-specific input.

Вступление

Я написал это руководство для изучения нового языка программирования. Тут не будет описания синтаксиса или шаблонов проектирования. Только основное направление для обучения. Ты должен сам выяснить, как реализовать проект на выбранном языке и фреймворке. Для начала определись с проектом, над которым будешь работать. Потом усложняй программу от терминала до веб-интерфейса с разделением на разные пользователей.

Choose an issue tracking system

You need to split your goal into several smaller tasks and track their status. For it, you need an issue tracking system. Create a ticket for each feature or bug and update its status in a timely manner. Choose any system that suits you (or your budget): Jira, GitHub, Trello, sticker board, etc.

Choose a version control system

Use Git. Make branch for each feature or fix. If there is anyone who is ready to do code review, then make pull requests. Then merge feature or fix into your development branch. Remember to use tags to mark versions and other useful metadata for commits.
